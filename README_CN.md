## 项目简介

本项目为自动售货机提供完整的电机控制固件解决方案，最多可控制 100 个电机。采用 10x10 矩阵配置驱动售货机中常见的各种电机，包括弹簧式出货器、电磁锁和履带式机构。

系统基于华芯微特（Synwit）SWM181 微控制器（ARM Cortex-M0 内核），通过 RS485 协议通信，适用于工业级自动售货机应用。

***

## 功能特性

### 电机控制

- **100通道矩阵控制**（10x10 矩阵，最多支持 100 个电机）
- **多种电机类型支持**：
  - 带反馈的弹簧电机（FB Motor）
  - 带反馈的电磁锁（FB Electromagnet）
  - 不带反馈的电磁锁（NFB Electromagnet）
  - 带反馈的履带电机（FB Crawler）

### 通信与安全

- **RS485 通信**，支持双通道
- **红外检测**，防夹手和货物检测
- **CRC16 校验**，确保通信可靠性
- **看门狗定时器**，保证系统稳定性

### 监控与升级

- **环境监测**（通过 Modbus RTU 读取温湿度）
- **电子锁控制**
- **XMODEM 协议**，支持固件升级

## 硬件架构

| 组件   | 说明                          |
| ---- | --------------------------- |
| MCU  | SWM181（ARM Cortex-M0，48MHz） |
| 通信   | RS485（双通道）                  |
| 电机驱动 | 10x10 矩阵（X-Y 控制）            |
| 位置反馈 | 10 通道位置反馈                   |
| 传感器  | 红外检测（NPN 型）                 |
| 电源   | 12V/24V DC                  |
| 调试   | SWD/J-Link 支持               |

### 矩阵配置

- **X 轴（列）**：10 通道用于电机选择
- **Y 轴（行）**：10 通道用于电机激活
- **反馈**：10 通道用于位置检测

## 通信协议

系统使用自定义帧协议通过 RS485 通信，采用 CRC16 错误校验。

### 帧结构

```
+------------+-------------+----------------+------+------+-----------+----------+
| 帧头       | 设备类型    | 设备地址       | 命令 | 数据 | CRC16 校验 | 帧尾     |
| 0xDDCCBBAA | 1 字节      | 1 字节         | 1 字节| 变长 | 2 字节     |0xFBFCFDFE|
| (4 字节)   |             |                |      |      |           | (4 字节) |
+------------+-------------+----------------+------+------+-----------+----------+
```

### 支持的命令

| 命令                | 值      | 说明            |
| ----------------- | ------ | ------------- |
| CMD\_OUTPUT       | `0x01` | 控制电机出货        |
| CMD\_READ         | `0x02` | 读取温湿度、锁状态     |
| CMD\_LOCK         | `0x03` | 控制电子锁         |
| CMD\_REPLY        | `0x04` | 响应帧           |
| CMD\_MODIFICATION | `0x05` | 修改设备 RS485 地址 |

### 响应码

| 代码                                     | 值      | 说明       |
| -------------------------------------- | ------ | -------- |
| RESULT\_VM\_FB\_MOTOR\_OUTPUT          | `0xC1` | 电机输出结果   |
| RESULT\_VM\_STATES                     | `0xC2` | 状态查询结果   |
| RESULT\_VM\_ADDR\_MODIFICATION         | `0xC3` | 地址修改结果   |
| RESULT\_VM\_LOCK                       | `0xC4` | 锁控制结果    |
| RESULT\_VM\_OUTPUT\_NFB\_ELECTROMAGNET | `0xC5` | 无反馈电磁锁结果 |
| RESULT\_VM\_OUTPUT\_FB\_ELECTROMAGNET  | `0xC6` | 带反馈电磁锁结果 |

## 快速开始

### 硬件需求

- **弹簧货道电机驱动板**（弹簧货道电机驱动板 V0816）
- **电源**：12V/24V DC（根据电机规格选择）
- **RS485 主控器**（用于通信）
- **电机**：弹簧电机、电磁锁或履带电机
- **调试器**：J-Link 或兼容的 SWD 调试器

### 软件需求

- **Keil MDK-ARM**（建议 5.0 或更高版本）
- **J-Link 软件**（用于调试和烧录）
- **串口终端**（用于 RS485 通信测试）

### 编译说明

1. **打开工程**：
   ```
   Code/spring_drive_V1.6/Project/spring.uvprojx
   ```
2. **选择目标设备**：SWM181xC 或 SWM181xB
3. **编译工程**：
   - 点击 `Build` 按钮或按 `F7`
4. **连接调试器**：
   - 将 J-Link 连接到板上的 SWD 接口
5. **烧录固件**：
   - 点击 `Download` 按钮或按 `F8`

### 通信测试

1. 将 RS485 连接到主控器
2. 设置波特率为 115200
3. 发送测试帧：
   ```
   帧头: AA BB CC DD
   设备类型: 01
   设备地址: 01
   命令: 02（读取状态）
   数据: 00 00 00 00 00 00 00
   CRC16: [计算值]
   帧尾: FE FD FC FB
   ```

## 默认配置

| 参数       | 默认值          | 说明                  |
| -------- | ------------ | ------------------- |
| RS485 地址 | `0x01`       | 设备地址（可通过命令 0x05 修改） |
| 广播地址     | `0xFF`       | 所有设备的广播地址           |
| 波特率      | 115200       | RS485 通信速率          |
| 设备类型     | `0x01`       | 电机驱动设备类型            |
| 帧头       | `0xDDCCBBAA` | 协议帧头                |
| 帧尾       | `0xFBFCFDFE` | 协议帧尾                |
| 看门狗      | 启用           | 系统看门狗定时器            |
| 最大通道数    | 100          | 最大电机通道数（10x10）      |

# 注意事项

- X 轴和 Y 轴映射遵循原理图设计
- 红外传感器使用 NPN 信号类型
- 电机反馈信号为低电平有效
- 确保电源电流容量满足所有连接电机的需求
